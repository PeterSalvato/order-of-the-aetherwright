The Order needs no equipment. A pencil is enough.

## Marking the work

When a work is finished, set aside or abandoned, write its Codex. Write the phases as they happened, and the glyphs in each phase in the order the domains became active.

## Where the Codex is written

- In the margin or footer of the work itself
- At the head of the notebook page where the work was planned
- In the header of the work's file
- In the message that records the work's last change

## Keeping the record

Keep every Codex in one place. Read together, a year of them shows which domains the member returns to, which they leave and how their work begins.

## The bench

A member's tools are named and kept in the same place, so that work starts in the same place each time.

> NOTICE. The Order is a designed notation in a ceremonial form. It asks for no belief. Its symbols are tools.
